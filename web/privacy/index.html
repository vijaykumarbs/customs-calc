Privacy policy

Last updated: 15 November 2026

CustomsCalc is an indicative India import duty and landed-cost calculator. This page explains what the service stores, why, and the choices you have. It covers the website at customs.vijayebhava.com and the REST API published on the same domain.

What we collect

  • An anonymous website cookie. The calculator sets a first-party, HTTP-only cookie named cc_client containing a random identifier. It is used only to count the five free calculations per Indian calendar day. It does not contain your name, email or payment details.
  • A hashed IP address. We hash the connecting IP address to apply abuse rate limits and a daily per-connection backstop. The raw IP is not stored in the application database.
  • Calculation records. For quota and abuse prevention we store the anonymous client identifier, HSN code, origin, assessable value, total duty, and a timestamp. These records are not linked to a name.
  • Email addresses. If you join the paid-plan waitlist or create an API key, we store the email address you submit. API keys are stored only as a SHA-256 hash; the plaintext key is shown once and cannot be recovered.
  • Standard server logs. Cloudflare, our hosting and CDN provider, processes request metadata such as IP address, user agent, path and timestamp as part of delivering and protecting the service.

How we use it

  • To provide the calculator, API and quota counters.
  • To prevent abuse, brute-force key guessing and quota evasion.
  • To reply about API access and the paid plan.
  • To understand aggregate usage and keep the service reliable.

We do not sell personal data, run third-party advertising, or use cross-site tracking cookies. Search terms and calculation inputs are not used to build advertising profiles.

Cookies

The only application cookie is the anonymous cc_client identifier described above. It is essential to the free-calculation quota. You can clear it in your browser; clearing it starts a new anonymous session, subject to the per-IP abuse backstop.

Sharing and processors

The service runs on Cloudflare Pages and Cloudflare D1. Cloudflare processes data on our behalf to host the site, run the Worker, store the database and protect the service. We may disclose information if required by law or to protect the service from abuse.

Retention

  • Anonymous quota counters: retained for the current and recent quota periods.
  • Calculation records: retained for up to 12 months for abuse review, then deleted.
  • Waitlist and API account emails: retained until you ask us to delete them or the account is closed.
  • Hashed API keys: retained until revoked.

Your choices

You can ask for a copy of the email address and API account details we hold, or ask us to delete them, by emailing privacy@vijayebhava.com. Because the website identifier is anonymous, we cannot link it to you unless you tell us the value. Deleting an API key immediately disables it.

Children

The service is intended for businesses and professionals. It is not directed at children under 18, and we do not knowingly collect their personal data.

Changes

We may update this policy as the service changes. The updated date at the top of this page will change when we do. Material changes affecting API customers will be announced by email where we have an address.

Contact

Privacy questions: privacy@vijayebhava.com. General and API questions: the API documentation.
