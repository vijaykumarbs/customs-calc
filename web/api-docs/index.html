Quickstart

Your first request in a minute

  1. Create a free key above. It starts with cc_live_.
  2. Send it in an Authorization: Bearer header on every request.
  3. Call GET /api/v1/hsn/85171300 for a rate stack, or POST /api/v1/calculate for landed cost.
Shell
export CUSTOMS_API_KEY="cc_live_your_key_here"

curl "https://customs.vijayebhava.com/api/v1/hsn/85171300" \
  -H "Authorization: Bearer $CUSTOMS_API_KEY"
Base URL https://customs.vijayebhava.com. All API responses are JSON and are sent with Cache-Control: no-store. CORS is open so browser clients can call the API directly, but never embed a key in a public web page.

Authentication

Hashed keys, bearer auth

Keys are generated once, stored as a SHA-256 hash, and never returned again. Send the plaintext key on every request using either header:

HTTP headers
Authorization: Bearer cc_live_xxxxxxxxxxxxxxxxxxxxxxxx
# or
X-API-Key: cc_live_xxxxxxxxxxxxxxxxxxxxxxxx

A missing or unknown key returns 401 missing_api_key or 401 invalid_api_key. A revoked key returns 403 key_disabled. Keys are rate-limited per minute as well as monthly.

One tariff line

POST /api/v1/calculate

Landed cost

Send hsn plus the customs value build-up, and an optional country. The country can be a name such as Japan, an ISO code such as JPN, an agreement column such as AIFTA, or omitted for MFN.

The assessable value follows the bill-of-entry build-up: goodsValue + freight + insurance + otherCharges. Send the invoice or FOB price as goodsValue; add only amounts that are includible in the customs value (freight to India, marine insurance, landing, packing, commissions, etc.). BCD, SWS, AIDC, cess and IGST are then applied to the resulting assessable value.

The legacy cif field is still accepted and is treated as the assessable value directly when no charge fields are sent. Do not send cif together with charge fields — use goodsValue instead.

curl -X POST "https://customs.vijayebhava.com/api/v1/calculate" \
  -H "Authorization: Bearer $CUSTOMS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"hsn":"85171300","country":"Japan","goodsValue":100000,"freight":5000,"insurance":1000,"otherCharges":500}'

POST /api/v1/calculate/batch

Up to 20 lines in one call

Send an items array with the same fields as a single calculation. Each line is validated first; the whole batch is rejected with the failing index if any line is invalid. Quota is reserved for every line atomically, so a batch either fits your remaining quota or returns 429 without consuming any calls.

Request
curl -X POST "https://customs.vijayebhava.com/api/v1/calculate/batch" \
  -H "Authorization: Bearer $CUSTOMS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"items":[
    {"hsn":"85171300","country":"Japan","goodsValue":100000,"freight":5000,"insurance":1000,"otherCharges":500},
    {"hsn":"85171300","country":"United Arab Emirates","goodsValue":50000}
  ]}'
200 response
{
  "data": {
    "count": 2,
    "quota": { "plan": "free", "limit": 10, "used": 4, "remaining": 6, "period": "2026-11", "resetsOn": "2026-12-01" },
    "results": [
      { "hsn": "85171300", "valuation": { "assessableValue": 106500 }, "amounts": { "totalDuty": 19170, "landedCost": 125670 } },
      { "hsn": "85171300", "valuation": { "assessableValue": 50000 }, "amounts": { "totalDuty": 18735, "landedCost": 68735 } }
    ]
  },
  "meta": { "indicative": true }
}

Batch limit: 20 items. The request body must stay under 8 KB.

GET /api/v1/search

Find a code without spending quota

Search by 2–8 digit code prefix or by words in the description. It returns at most 25 results and never includes rates, so lookup is free for every signed-in key.

Request
curl "https://customs.vijayebhava.com/api/v1/search?q=smartphone&limit=5" \
  -H "Authorization: Bearer $CUSTOMS_API_KEY"
200 response
{
  "data": {
    "query": "smartphone",
    "results": [
      { "code": "85171300", "description": "Smartphones" }
    ]
  },
  "meta": { "count": 1, "note": "Search is free and does not use quota." }
}

Conventions

Response shape and units

  • Every success response wraps its payload in data; optional context lives in meta.
  • Rates are percentages, not fractions. 15 means 15%.
  • All money amounts are Indian rupees, rounded to two decimals.
  • goodsValue must be greater than zero. freight, insurance and otherCharges are optional and default to zero.
  • valuation.assessableValue is the CIF value used for BCD, SWS, AIDC, cess and IGST. cif repeats it for compatibility.
  • amounts.dutyBeforeIgst is BCD + SWS + AIDC + cess; amounts.totalDuty is the total payable to customs including IGST.
  • The legacy cif field is accepted as a direct assessable value when no charge fields are sent.
  • Every billable response includes a quota object with limit, used, remaining, period and resetsOn.

Data coverage

What the numbers include

  • 11,906 of 14,416 codes carry a line-level statutory BCD from the CBIC working-tariff PDFs as on 30.06.2025. The rest are dataset-only and flagged.
  • 144 compound or specific-duty parses are approximate and flagged.
  • Effective BCD differs from statutory BCD only on curated high-volume lines.
  • AIDC is populated only for gold and silver.
  • Mauritius, Chile, Mercosur, APTA and GSTP are limited PTAs shown at MFN.
  • The UAE CEPA column uses 533 curated line-level rates.

Rates are indicative and not legal or customs advice. Anti-dumping duty, safeguard duty, tariff-rate quotas, specific duties, valuation adjustments and origin verification are excluded. Confirm every rate on ICEGATE before filing a Bill of Entry.

Rules and limits

Fair use

  • One key per email. Signup is limited to three keys per IP per day.
  • Search is capped at 300 requests per hour per key and 25 results per request.
  • Lookups are capped at 120 per minute and calculations at 60 per minute.
  • Do not resell the raw dataset, bulk-download descriptions, or share a key between unrelated applications.
  • Keys can be revoked or rotated by the operator at any time.
